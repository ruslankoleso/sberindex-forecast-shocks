# Прогноз потребления в МО и раннее обнаружение шоков

Решение кейса СберИндекса «Прогнозирование и обнаружение точек структурных изменений»: прогноз безналичных потребительских расходов в 2 190 муниципальных образованиях на 1, 3, 6 и 12 месяцев и обнаружение шоков, совмещённое с прогнозом.

- **Объяснение простым языком:** [docs/EXPLAINED.md](docs/EXPLAINED.md)

## Главные результаты

**Прогноз** — средняя ошибка (MAE), руб. на жителя в месяц, проверка скользящим окном по 2024 году:

| Модель | 1 мес. | 3 мес. | 6 мес. | 12 мес. |
|---|---:|---:|---:|---:|
| Prophet (базовая модель) | 1 805 | 1 755 | 2 159 | 2 901 |
| Сезонная наивная модель с дрейфом: «тот же месяц год назад × рост России» | 1 250 | 1 108 | 1 143 | 1 416 |
| Chronos-2, дообученный | 1 413 | 1 660 | 1 860 | 2 234 |
| TimesFM 2.5, дообученный (LoRA) | 1 119 | 1 568 | 1 673 | 2 194 |
| Chronos-2, дообученный, backcasting со смесью форм года | 1 068 | 1 314 | 1 533 | 1 614 |
| TiRex (zero-shot, backcasting) | 1 335 | 1 908 | 1 997 | 3 086 |
| **Ансамбль с весами по обратной ошибке (по скользящему окну)** | **1 010** | **1 131** | **1 114** | **1 416** |

**Обнаружение шоков** — лучший метод: детектор по остаткам прогноза сезонной наивной модели с дрейфом. На искусственных шоках находит 61 % (сдвиги 20 % — 88–97 %), реагирует на разовые выбросы в 5 % случаев; для России в целом — BOCPD (кризисы 2020 и 2022 годов найдены, лишних тревог нет).

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Веса фундаментальных моделей скачиваются с Hugging Face при первом запуске (Chronos-Bolt, Chronos-2). Для TimesFM и TiRex в `configs/foundation.yaml` указаны локальные пути `models/…`: если загрузчик Hugging Face работает, замените их на `google/timesfm-2.5-200m-pytorch` и `NX-AI/TiRex`, иначе скачайте файлы в `models/` вручную.

## Запуск

Все гиперпараметры — в `configs/*.yaml`, seed фиксирован.

```bash
# 1. Данные: панель МО из набора организаторов
.venv/bin/python -m src.data.load

# 2. Внешние данные (ключевая ставка, курс, производственный календарь)
.venv/bin/python -m src.external.macro

# 3. Прогноз: модели на скользящем окне → data/interim/forecasts, метрики → data/interim/metrics.csv
.venv/bin/python -m src.eval.run --models naive seasonal_naive snaive_natg prophet lgbm_resid chronos2_ft
#    ансамбль с весами по обратной ошибке по сохранённым прогнозам
.venv/bin/python -m src.eval.ensemble

# 4. Обнаружение шоков: бенчмарк детекторов, реальные кризисы РФ, шоки в МО за 2024 год
.venv/bin/python -m src.changepoint.benchmark
.venv/bin/python -m src.changepoint.national_events
.venv/bin/python -m src.changepoint.panel_shocks

# 5. Новости: сбор заголовков, привязка к МО и месяцам, оценка пользы
.venv/bin/python -m src.news.collect
.venv/bin/python -m src.news.features
.venv/bin/python -m src.news.evaluate

# Тест на отсутствие заглядывания в будущее
.venv/bin/python -m pytest -q tests
```

Список всех моделей — словарь `REGISTRY` в `src/eval/run.py`. Каждая модель запускается в отдельном процессе (на macOS torch и многопоточный LightGBM в одном процессе конфликтуют).

## Структура

```
configs/        гиперпараметры (YAML)
data/raw/       исходные данные: organizers/ — набор организаторов, остальное — открытые ряды СберИндекса по России
data/external/  справочник МО → регион (ОКТМО), макроданные, новости
src/data/       загрузка панели
src/eval/       скользящее окно, метрики (MAE, R²), ансамбль
src/forecast/   модели: бейзлайны, Prophet, LightGBM, сезонная наивная с дрейфом, гибрид с моделью остатков, фундаментальные модели
src/changepoint/ детекторы шоков и их оценка
src/news/       сбор и согласование новостей
src/external/   внешние данные
tests/          тест на утечку будущего
docs/           объяснение, журнал решений, описание данных
```
