## Особенности МО-файла
- **Нет id муниципалитета и справочника**, только название (`mo`). Колонка `value` — рубли, не id.
- 49 названий принадлежат нескольким МО (например, «Александровский муниципальный район» — 3 разных ряда).
- Строки идут блоками по 24 месяца в порядке, перемешанном между МО и категориями.

## Как собираем id (`src/data/load.py`)
- Блок строк с одним (МО, категория) и растущим периодом = отдельный ряд.
- Для «Все категории» блоки одного названия = разные МО → id `Название #1`, `#2`, … (121 такой МО).
- Категории привязываем к МО венгерским алгоритмом по устойчивости доли в общих расходах. На искусственных парах точность 95 % (2 дубля) и 88 % (3 дубля), поэтому категории используем только как дополнительные признаки.
- Результат: 2 190 МО (по названию было 2 118), 2 016 МО с полными 24 месяцами, 174 — с неполной историей. Дублей (МО, категория, период) нет.

Воспроизведение: `python -m src.data.load` → `data/interim/panel.parquet`, `mo_directory.parquet`.

## Наблюдения EDA (2 016 полных МО)
- Сильная сезонность: декабрь +19 % м/м почти у всех МО (98–99 %), январь −23 %, сентябрь −7 %, апрель −8 %.
- Рост в феврале–марте повторяется в 2023 и 2024 — это сезонность, а не разовый шок.
- Медианный рост г/г в 2024: январь 7 %, апрель 19 %, дальше 14–17 % — возможная смена режима в начале 2024, проверим детекторами.

Проверки:
- `consumption` совпадает со старой выгрузкой: те же 303 126 строк, 2 190 территорий, 2 016 полных рядов, значения всех 2 016 рядов идентичны. Наш восстановленный по названиям id дал ровно 2 190 МО, т. е. восстановление было верным по числу рядов; названий в папке нет (справочника с id → название организаторы не приложили), но по совпадению рядов все 2 190 `territory_id` однозначно сопоставлены названиям.
- `territory_id` упорядочены по регионам (id 1 — Майкоп, рядом Адыгея), поэтому соседние id — территории одного региона.
- Граф шире панели: в `connection` 2 574 территории, в `consumption` 2 190; 401 территория есть в графе и `market_access`, но без расходов; 18–20 территорий с расходами в графе нет (острова, без дорожного сообщения).
- Расхождение с описанием: в PDF «1 447 МО без железной дороги», в данных железная дорога есть у 1 627 территорий (ожидалось около 1 127).
- Расстояния `highway` в основном записаны в одну сторону (x>y в 98,5 % пар), `railway` — в обе стороны; при построении графа нужна симметризация.
- 148 пар `highway` с расстоянием 0 км.
- Население МО в папке отсутствует (индекс доступности рынков использует его, но самих значений нет).

## Как теперь собирается панель
`python -m src.data.load` читает `consumption.parquet` и пишет `data/interim/panel.parquet` (territory_id, period, category, value) и `territories.parquet` (число месяцев по территории). Проверка при переходе: бейзлайны на новой панели дали MAE, совпадающие со старой выгрузкой до знака, значит ряды идентичны.

Справочник `data/external/territory_reference.parquet`: territory_id → название (восстановлено сопоставлением рядов со старой выгрузкой, названий в данных организаторов нет), регион по ОКТМО, источник привязки и флаги Москва / Мособласть / СПб.
